# Curriculum bundle

Open `computer_science_systems_curriculum_v2.html` in a browser for the interactive offline view.

Use these files from an IDE or agent:

- `computer_science_systems_curriculum_v2.md` — complete human-readable curriculum.
- `computer_science_systems_curriculum_v2.json` — machine-readable phases, weeks and resources.
- `AGENT_TUTOR.md` — tutoring behavior and grading contract.
- `progress.md` — progress template for all 60 weeks.
- `templates/DESIGN.md` — mandatory pre-code design template.
- `templates/RETROSPECTIVE.md` — weekly retrospective template.

All required learning resources are linked from the curriculum and are intended to be freely accessible.
