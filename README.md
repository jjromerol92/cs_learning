# Source-grounded curriculum v3

Start with:

1. `computer_science_systems_curriculum_v3.html`
2. `baseline.md`
3. `weeks/week-01.md`

Important files:

- `source_syllabus_inventory.md` — full subject-by-week inventory.
- `weeks/week-XX.md` — exact official units, official work, mastery targets and
  the prompt “Let's do the groundwork for Week XX.”
- `AGENT_TUTOR.md` — source and anti-hallucination rules.
- `progress.md` — evidence tracker.
- `computer_science_systems_curriculum_v3.json` — machine-readable manifest.
- `CHANGELOG_FROM_V2.md` — corrections made.

The nominal 60 weeks define order, not hard deadlines. Large official projects
may take more than one calendar week.
